# 验证记录

验证环境：STM32F407 C 板，ST-Link，Keil ARM Compiler 6.19，Scope 0.4.5，2026-10-22/23（北京时间）。

## 编译与算法

- Keil：0 Error、0 Warning，约 19 KB 程序；生成 AXF、HEX。
- CMake Debug / ARM GCC：构建通过，Flash 约 30 KB、RAM 2696 B。
- MinGW C++11：12010 项断言通过，覆盖运动打断校准、已知零偏恢复、静止 yaw、三轴组合运动、yaw ±180° 跨界、反馈收敛与非法输入。
- STM32CubeProgrammer：烧录 Keil HEX、读回校验成功，复位运行。

## 静态实板

通过 Scope 的真实 `stlink` 配置读取 RAM，加载与固件匹配的 Keil AXF；未使用 mock 数据。采集 5000 帧，跨度约 101.74 秒，Scope 请求 50 Hz。

| 项目 | 观测 |
| --- | --- |
| 加速度计 / 陀螺仪 ID | `0x1E / 0x0F` |
| 初始化 / 校准标记 | `1 / 1` |
| 板上采样频率 | 500 Hz |
| 采样 dt 范围 | 1.99958～2.00048 ms |
| SPI 失败 / 丢失节拍 | 0 / 0 |
| roll 范围 | -1.220～-1.130° |
| pitch 范围 | 0.132～0.198° |
| yaw 范围 | -0.372～-0.010°，相对角度 |
| 校准前三轴角速度均值 | 0.1851 / 0.0654 / 0.0851 °/s |
| 校准后三轴角速度均值 | -0.0053 / 0.0010 / 0.0019 °/s |

校准消除静态均值，噪声仍然存在。Scope 通过 SWD 顺序读取变量，采集帧中的多个值可能来自邻近固件采样时刻。

运行中测试 `imu_use_dma=0`：采样继续以 500 Hz 进行，DMA 计数停止，错误与丢失节拍仍为 0。恢复为 1 后 DMA 计数继续增加。

写 `imu_recalibrate=1` 后约 0.3 秒读取到 `imu_calibrated=0`、进度约 153；再过约 2.1 秒，进度达到 1000、标记为 1，yaw 回到接近 0。

写 `imu_algorithm=1` 后输出切换至 Mahony，测试结束恢复为 0；默认 DMA=1。

本次完成的是静态实板和数值算法验证。绕三轴转动 C 板的动态画面由验收视频记录，录制步骤见 README。
